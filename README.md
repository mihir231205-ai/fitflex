# FitFlex

A complete React fitness platform for mapping muscle groups, following home or gym workouts, checking BMI, searching healthy recipes, inspecting nutrition, and choosing a training goal.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (typically `http://localhost:5173`).

## User journey

Choose Male/Female → rotate the body model → select a muscle → choose Home or Gym → watch workout videos.

Additional pages: BMI Calculator, Diet Plan, Nutrition Checker, Fitness Goals, and About.

Sample data lives in `src/data`. API adapters in `src/services/catalog.js` can be swapped for live nutrition, YouTube, exercise, and diet endpoints later.
